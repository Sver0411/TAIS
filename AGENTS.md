# Research and report boundaries

- Preserve frozen historical algorithms, configurations, raw results, upstream
  submodules, metric definitions and negative results. New research is additive.
- Personalized reports for any professor must be generated only into a local
  directory outside this Git repository. Never stage, commit or push them.
  Do not put professor-specific research narratives into public README files or
  generic project documents. Do not run a historical report writer that would
  violate this rule; retain historical evidence without regenerating it.
- Generic code, experimental data and technical documentation remain ordinary
  project artifacts. Phase4 public documentation must remain audience-neutral.
- Phase4 does not authorize a GitHub push or a default-policy replacement.
- Seeds900–919 are MA-1 diagnostic data only. Seeds0–899 remain reserved.
  New engineering and final cohorts must be audited, distinct and frozen.
