## 6. 拟议研究假设、比较与可证伪条件

研究问题：在因果可获得信息、测量频率及资源预算受约束时，同物理量空间参照是否能降低漂移诱发误报，同时保留局地真实变化的召回？以下均为待检验命题，没有本阶段结果支持其成立。

- **H1**：相对单通道主基线，漂移诱发错误环境报告减少；局地事件召回差值不低于预先给定的非劣界限 `−δ_local`，且总误报与成本满足预登记约束。若任一主条件不成立，不能宣布联合假设成功。
- **H2**：空间参照的增益优于等信息/资源预算的同通道历史对照，也优于无信息参照负对照。仅胜过一个弱对照不足以支持“空间信息增量”。
- **H3**：共同故障、参考缺失、不可信参考、局地变化与信息完全擦除属于必须报告的边界；不预设逐例可分。相同在线输入对应不同真实状态时，任何确定性策略都不能保证两者逐例正确。

`δ_local`、可接受总误报增量、最小实际收益和预算上限目前**未赋值**。尚无足够应用依据，不能从既有合成结果或未来验证效果反推有利门槛；门槛未定即不可冻结，不得用显著性替代实际意义。

### 6.1 两阶段设计

## 7. 时间、身份和因果信息规则

### 7.1 时间块与暴露纪律

**不填写最终日历边界。** 目前没有充分时间语义来确定它们，甚至不能用 Hull 源行号的前后顺序替代真实日期。未来补证后，在任何效果分析之前按可信日历的连续完整时间块形成开发→验证→最终测试，所有同站点节点使用相同分界，不随机拆行。

拟采用时间顺序开发/验证/最终测试，比例和精确边界仍待覆盖与统计独立性论证；不能以行数相等替代时间长度。最终 manifest 必须列区间、有效暴露、排除原因、目标/参考范围、原始 SHA 和数据视图版本。不能切出最容易同步的少数时段后不报告其余时段。

边界隔离带至少覆盖模型最大历史长度、健康初始化历史、测量年龄上限、聚合窗口宽度和最长事件/注入及恢复影响，按各项依赖范围取足够长度并在冻结表给出具体值。重叠窗口、同一自然事件、同一注入及其恢复尾段不得跨分区；整段分配或整段隔离，不能跨界分成独立样本。

开发数据可用于预定参照、滞后、阈值和模型选择；验证只执行提前登记的有限方案决策，不能无限调参。最终测试不用于选参照、调参数、改清洗、设门槛、挑场景或修改报告规则。初始化只允许同分区预留的先行历史且不计分，不从测试未来或验证评分区借“健康历史”；没有健康真值的历史仅是未标注初始化背景，不能称已知健康。

### 7.2 可用性账本与因果对齐

未来每条可用记录至少有：原始文件 SHA、行号、站点/节点、物理量、原始时间、可信采集/聚合区间 `[s,e]`、可用时刻 `a`、身份/时间可信度、有效性和获取成本。**`a` 不等于文件中能解析出的 timestamp。**

决策时刻 `t` 的允许信息集仅含身份可信且 `a ≤ t` 的记录，并须满足聚合已结束 `e ≤ a`。若有时钟不确定性，用有依据的最晚可能结束/可用时刻约束；未知偏差不默认 0。聚合窗口锚点未明时不能偷偷采用“末端时间戳”；远端日末上传的数据不能在同日早晨免费使用。

对齐只能从已经可用的过去记录取值，明确参考测量年龄 `t−e` 及上限；禁止最近邻选择未来值、向后填充、居中平滑、双侧插值、测试期最优滞后或按全文件序号构造实时顺序。age 上限、时钟容忍度、可用参考数下限须在冻结前给出依据和值，不能根据测试效果调整。

参考缺失、过龄、不可信或预算不足时显式返回“不可用”，未来候选必须有提前声明的降级/拒答路径；不能靠“无参照就忽略该例”提高召回。评价分母保留这些例，另报可用覆盖、拒答、漏检和成本。没有来源支持 `a` 或会话映射时，该数据集不进入因果主分析；即使允许另立假设延迟敏感性研究，也必须标明假设回放，不声称复现真实网络到达。

## 8. 真值、指标与配对统计

### 8.1 真值层次

| 漂移诱发误报 | 在同背景/采样/事件真值的有无漂移配对中，报告严格错误报告的净变化及新增/消失列表；同时单列仅漂移掩码内的严格错误报告。无完整标签时只报干预额外报告，不越级命名 |
| 总体及局地事件召回/漏检 | 对独立事件列表逐事件匹配；目标节点和物理量一致，按开始时间排序，取预登记允许窗口内最早未匹配报告，一对一匹配。局地/共同、重合/不重合、缺失参考各分层；无事件分母为 N/A |
| 匹配窗口/重复报告 | 起点容忍、最大报告延迟、相邻事件合并和恢复边界依据原生分辨率与应用需求冻结。不能在测试后扩大窗口；同事件重复报告不增加 TP，标为重复，已知负掩码内计严格错误，其余未核验报告单列 |
| 检测延迟 | 匹配报告时刻减事件起点，报告中位/分位数及未检测数量；不能只用检出事件的短延迟掩盖漏检。若起点是区间，给延迟区间；预定截止期未检出按删失/漏检报告 |
| 误报持续时间/状态占用 | 在独立负标签掩码内积分错误环境状态持续时间，另列未知标签区间、全部告警占用及不可用占用；状态区间截断于统一观察终点，不用插值填补真值 |
| 采样/诊断/参考测量 | 同时计目标/参考通道读取次数、节点唤醒周期、诊断读取、请求失败和缓存命中；不能把多通道读取全算一条而隐藏参照成本 |
| 上传/载荷 | 环境报告、心跳、故障变化、参考请求/响应与重试分别计应用请求及序列化字节；固定编码/包格式后冻结。总预算含参照侧，不只计目标上传 |
| 重建误差（次要） | 如适用，在共同存在原生目标值的固定网格上比较 MAE/RMSE，报告覆盖和缺失；参考值不得充当目标真值，不评估未发布的高频信号 |

没有真实电流测量或可验证的无线电模型，不报告焦耳节省。到达延迟不明时，也不报告真实在线端到端检测延迟。自然背景上无标签的总报告数不是“总误报”。

### 8.3 主比较、配对和不利结果

拟议主比较为 A 阶段 S-X 对 S0 的漂移错误报告变化与局地召回保持；H2 为 S-X 对 S-H、S-N。最终冻结时明确每个比较的预算、主场景权重和主终点，不以“所有参数任取一个成功”检验假设。

以独立时间块为配对单位，同块全部空间节点共同保留，全部方法共享输入与干预。节点、重叠窗口和同一注入重复次数不当成独立样本。块内先汇总计数/暴露和事件分母，再按预登记的相同权重比较；同时报告汇总分子/分母，不能利用不同覆盖改变排名。不同数据集分开分析，不能把实验室与一座温室合并成许多独立农业部署。

拟定方法为**配对时间块 cluster bootstrap**，完整重抽时间块及块内全部节点和方法，10,000 次，报告差值和双侧 95% 百分位置信区间。块长/最少独立块数由开发期依赖范围与精度/功效目标论证，并在最终数据打开前冻结；bootstrap 随机种子也须审计固定。独立块不足时只作描述，不用逐行 bootstrap 获得虚假的窄区间。延迟报告检出子集与包含未检测的截止期结果；无事件或零有效负暴露的块不赋假零，分母缺失单列。

H1 需要错误报告差值区间支持预登记的减少幅度，同时局地召回差值下界大于 `−δ_local`，并满足成本和总误报约束；区间跨界为不确定，非显著不等于非劣。H2 的两个优效主比较拟用 Holm 方法控制家族错误率 0.05；明确标注原始 95% 区间与多重比较判定的区别。联合主终点及其他多个预算/场景如何纳入检验家族，必须在冻结表中完整列明，否则不作确认性声明。

所有预定场景、预算点、节点覆盖、拒答、无效块和不利差值一并报告。共同故障、局地事件损失、误报增加、参照成本过高与数据不足都可推翻研究主张；不得只汇总尖峰恢复或挑最优点。A 的收益不自动外推 B、自然故障、其他温室或更快时间尺度。
