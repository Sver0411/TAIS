## Mechanisms and parameters

The authoritative machine-readable specification is `configs/tais-transfer.json`, version `transfer-v1`. Each run has 1,800 dense integer source timestamps, 0–1799 s, and two channels. These are engineering stress distributions, not estimated agricultural distributions.

For channel c, background state follows `b[t]=b[t-1]+0.003(target[t]-b[t-1])+s_c z[t]`. Initial temperature center is uniform22–28°C and humidity40–60%RH. Targets change after uniform-integer180–360s: center plus Gaussian SD0.35°C/1.75%RH. Innovation SD is0.006°C/0.03%RH. Within each segment, humidity innovation is `rho*z_T+sqrt(1-rho²)*z_H`, with rho uniform−0.65 to0.2, independently redrawn across segments. Thus correlation is limited and changes rather than prescribing a fixed inverse sinusoid.

Observation noise is independent of background and event draws. `eta[t]=r*eta[t-1]+sqrt(1-r²)*epsilon[t]`, with channel-specific r uniform0.65–0.9. Multipliers uniform0.6–1.8 change every120s; channel scales are0.08°C/0.4%RH. Innovations are standard Gaussian with independent probability0.002 of an additional `3*t_3` perturbation, implemented using a Gaussian divided by the square root of Gamma(shape1.5, scale1/1.5). These occasional noise tails are not labeled sensor faults. Initial AR state is zero, without a future burn-in.

Each event-enabled channel has three exogenous events. Short12–40, medium41–100 and long101–240 seconds are randomly permuted across onset strata180–300,660–780,1140–1260 seconds. Shapes (also permuted) are: (i) immediate step, constant through70% support then exponential recovery `exp[-10(u-.7)]`; (ii) `sin²(pi*u)` pulse; (iii) asymmetric beta-shaped pulse `u(1-u)^4/(.2*.8^4)`. Here u=(elapsed+.5)/duration. Signed amplitudes are uniform1.8–4.8°C or6–18%RH. Time strata prevent event overlap within a channel, not fault overlap; no schedule uses sampling times. A small step back to baseline at support end is part of the defined finite pulse, including the exponential tail's nonzero last value.

**Truth:** every injected event has half-open physical support `[start,start+duration)` and inclusive scoring window `[start,start+duration-1]`, independent of its amplitude/shape and of any ChangeAnalyzer threshold. Unlike G1's amplitude-derived interior labels, G2 scores the entire exogenous intervention support. This difference is explicit; absolute G1/G2 rates are not identical tasks. Retain event ID/channel/amplitude/shape/support, actual sampled coverage, finite-valued sampled coverage, and sender/decoded receiver report times. A ±5s match tolerance remains frozen. It permits occasional matches without a sample strictly inside support; these are reported rather than described as prediction.

Fault starts are uniform-integer150–1300s; core durations120–360s, signed magnitudes, with30–100s linear recovery tails for drift/offset. All other faults end abruptly. Range is a replacement by −55 or110°C, or −20 or125%RH, outside the public physical ranges [−40,85]°C/[0,100]%RH. Invalid is IEEE NaN; missing is None. Stuck freezes the actual noisy reading at its fault start. Spike has three randomly positioned1–3s bursts within the independent core interval, merging touching bursts into distinct fault episodes. Magnitudes are signed6–18°C/20–50%RH. Offset is signed0.8–3.2°C/3–12%RH. Drift integrates three same-sign independently drawn slopes (0.003–0.02°C/s,0.015–0.08%RH/s) across thirds of the core interval, then tapers the accumulated displacement. No online estimator uses these schedules. JSON archives normalize nonfinite numeric values to null using the existing canonical serializer; the stored fault kind/schedule records the distinction between injected NaN and missing None, and regeneration restores the precise Python values.

## Scenario matrix and independent random streams

46 scenarios: clean no-event; clean temperature events; clean humidity events; clean both-channel events (six); plus7 kinds ×2 fault channels ×3 event arrangements (none, same channel, other channel). Event-enabled fault runs contain three events. Temporal before/after/overlap/nonoverlap relations arise from independent schedules and are classified offline, not forced using a fault-relative event offset or selected by detector results. All instances remain even if no sampler can observe an event. The independent formal run verifies that each required temporal category is present.

SHA256(`tais-transfer-v1:seed:stream`) first128bits seeds independent Python RNG streams: `environment`, `noise`, `events:family`, `fault:channel`. Environment/noise are shared across fault kinds and channels for a seed; event family (none/temperature/humidity/both) determines only the independent physical event schedule. Fault stream is independent of all event/background/noise streams. Shared draw ranks across fault channels create paired comparisons without assuming equal physical units. No acceptance/rejection step, future-label screening, or detector-conditioned generation exists.

Clean counterfactual is an exact copy with observed=noisy and faults=[]; no RNG is called. The cache key hashes the complete fault-free observed sequence **and** event labels plus method name, not old relation/profile names. Each source trace, schedule, result, frame, receiver log and counterfactual is archived and fingerprinted. Policy receives a facade containing only observed rows. It never receives Trace metadata, scenario, seed, labels, latent/noisy data or hidden centers. Causality tests replace unsampled values and truncate future rows.

## Interpretation and failure rules

If F1/Recall advantage reverses or its interval spans zero, retain it and narrow the claim. An increased sample budget cannot establish equal-budget superiority. Byte savings may be reusable U behavior, not unique TAIS sampling novelty. More samples can increase fault-induced reports; fewer uploads can increase age. Two independently specified synthetic mechanisms are stress evidence, not real farms, natural faults, measured radio delivery or battery energy. A second mechanism can support a publishable reproducible design/tradeoff study even with mixed outcomes; it cannot make known components new. No extra algorithm optimization or further planned generator-selection loop follows this campaign.
