## What is established prior art

Adaptive/event-driven sampling, statistical volatility estimation, confidence-based fault-aware event detection, prediction/data suppression, joint sampling/communication control, and quality/resource tradeoffs all have precedents above. SensorTrust C11 and AdaptiveSense are separately pinned software dependencies, not newly invented algorithms in this manuscript. Deadband/heartbeat emission and stateless encoding are engineering choices, not new compression theory. “Different budgets lead to different recall” is not a mathematical novelty claim.

## Defensible contribution candidates and proof obligations

1. An executable integration of unchanged health diagnostics, causal event-aware schedules, emission and receiver reconstruction. Evidence: `scheduler.py`, `su_policy.py`, `joint_upload.py`, `wire_codec.py`, `core_stream.py`; frozen behavior retained.
2. An auditable evaluation separating native sender reports, decoded receiver edges and common-detector schedule effects. Evidence: `paper_baselines.py`, `paper_metrics.py`, per-run archives, actual encoded lengths and seed-cluster intervals. This is a reproducibility/systems contribution, not an algorithmic first.
3. Conditional operating points that may improve detection and software cost together relative to specific named baselines. This is a result only when the actual CSV supports every named metric; never imply dominance over all fixed/adaptive competitors or equal budgets without qualification.
4. Empirical boundaries: sampled visibility, complete same-channel masking, stable offsets, drift ambiguity, extra fault reports, data-age cost, and failed H layer. Case/group evidence and historical reports establish observed failures, not universal impossibility except information erased or never observed.

The evaluation deliberately retains every fixed period, all native curve points, failed cap-only budget calibration, and all scenarios. Rao-inspired and original Delta/Variance controls are independent schedulers but use a shared external detector. +C11 is a metadata-only extension; +C11+U explicitly includes a TAIS component. The common-detector view is a scheduler study. No faithful literature reproduction was completed; none is claimed.

## Rao implementation mapping (not reproduction)

Read Section3.1 CS measurement/reconstruction (Eqs1–4), Section3.2 previous-day tolerance (6–8), and Section3.3 sparse/dense switching (9–15). Four-point least-squares prediction in `IndependentSampler.update`, Rao-inspired branch, is inspired by Eq11 and boundary intersection Eq12/13. We use actual seconds, not original-interval indices. Dense5s vs bounded sparse cap, prior center-centered bands, current-excursion guard, one-cap prediction horizon and75% return hysteresis are local engineering definitions. All thresholds are development-selected noise-floor multiples. Four points,60s stable dwell and5–60s bounds are new local parameters, not attributed to Rao. No previous-day APDT/Student-t, original gamma/mu, CS/SL0, sink training, prediction substitution or model synchronization. Unlike Rao, every observed sample uploads in native mode; this baseline evaluates sampling only. Input is two sampled scalar channels, output next sampling interval; original output includes recovered/predicted data and network traffic.

Rao text contains apparent directional inconsistencies around critical-zone wording in3.1 and sparse return wording in3.3; this is another reason to avoid claiming verbatim algorithm fidelity. We use the Section3.3/Figure2 narrative idea only and disclose all departures. Full XML fingerprint retained; no invented paper formula/parameter.

## Positioning judgment

Prior work already combines fault tolerance with sampling and combines sampling with communication. Thus “first integrated trust-aware joint optimizer” is not justified by this review. A suitable claim is **reproducible simulation-based design and trade-off analysis for a bounded single-node prototype**. Strength depends on independent near-budget evidence, honest adverse comparisons and clear receiver semantics. One synthetic family and no faithful external-method reproduction remain important submission weaknesses. A new-algorithm journal claim is presently unsupported; workshop/short systems paper or application-oriented reproducibility track is more plausible, subject to the final review.
