# TAIS 投稿准备清单

本轮内容大修结束后转入渠道选择、模板适配和提交准备。以下未勾选项是需要人类作者提供或按目标渠道确认的事项，不是已经完成的审批，也不要求追加算法或仿真实验。

## 人类作者与稿件责任

- [ ] 填写真实作者姓名、顺序、单位、通讯作者及ORCID；取得全部作者对最终稿的明确同意。
- [ ] 人工逐项审阅代码生成、分析、引用和论证；确认是否符合目标渠道的作者资格标准。不得以“TAIS Research Project”占位符直接投稿。
- [ ] 如实填写资金、利益冲突、数据/代码可用性声明；未知信息不得自动填“无”，不编造导师、资助或伦理批准。
- [ ] 根据盲审规则制作匿名版；移除身份和可能破坏匿名性的仓库链接时，按渠道允许的匿名材料方式提供可复现证据。

## 渠道与研究定位

- [ ] 选择接受仿真系统评价、资源权衡或可复现性研究的范围；不以全新信任理论、普遍优效、实际农业效果或实测节能为卖点。
- [ ] 核对页数是否含参考文献/附录，是否允许独立补充材料；当前完整证据附录可按规则拆分，不能删除不利结果。
- [ ] 检查模板、图表分辨率、字体嵌入、DOI样式、开放代码/数据要求及软件MIT归属。
- [ ] 核对预印本/公开GitHub政策、是否存在一稿多投、费用与版权条款；未选择渠道前不声称满足某一具体会议/期刊全部规则。

## AI工具使用披露：按选定渠道现行规则执行

已于2026-10-19查阅官方规则，不能假设所有出版社或所有年份采用相同规则：

- **IEEE**：作者中心现行规则要求披露文章中AI生成的内容，范围包含文字、图像和代码，并说明工具与涉及部分。具体渠道和轻量语言编辑例外仍需核对。[IEEE Author Center](https://journals.ieeeauthorcenter.ieee.org/become-an-ieee-journal-author/publishing-ethics/guidelines-and-policies/submission-and-peer-review-policies/)
- **Elsevier journals**：现行政策区分稿件准备与研究过程中的AI使用；要求对相应使用透明说明，不能以AI代替人类责任。选择具体期刊后核对声明位置、研究方法披露及图片规则。[Elsevier policy](https://www.elsevier.com/en-gb/about/policies-and-standards/generative-ai-policies-for-journals)
- **ACM**：中央作者政策页面本次返回403；可检索到的不同年份活动页面出现不同版本表述，因此此处不代替目标渠道给出统一规则。投稿前应直接核对中央最新政策及该渠道说明，尤其区别AI辅助写作和AI参与研究过程。[ACM authorship policy](https://www.acm.org/publications/policies/new-acm-policy-on-authorship)

- [ ] 如实确认OpenAI Codex对实现、仿真执行支持、分析脚本、图表代码及文字修订的实际参与范围，记录工具/版本与用途；不要将本项目描述成仅做了拼写检查。
- [ ] 稿件中的草拟披露尚不代表人类作者已完成独立复核或同意。人工确认后按目标渠道调整Methods、Acknowledgements或单独声明部分。
- [ ] 图表来自冻结CSV的确定性绘图和TikZ架构代码；没有AI生成的虚构测量图。仍须按渠道对AI辅助绘图代码/设计的规则披露。
- [ ] AI不能作为作者，责任不能转移给工具；不编造“人工已核验全部内容”的完成状态。

## 提交前最终技术检查

- [ ] 在最终模板中重新编译并渲染全部页面，检查黑白可读性、引用和编号；当前审核证据不能替代模板转换后的检查。
- [ ] 再运行 `scripts/build_paper.py`、`scripts/check_paper_artifacts.py`、`scripts/verify_paper_revision.py`。
- [ ] 确认原G1/G2 CSV与指纹不变，预算敏感性仍标为事后资格分析，CI对应提交全部通过。
- [ ] 用最终PDF逐句核对摘要：任务及标签差异、F1跨零、Fixed20不利点、共享U、无硬件能耗均保持准确。

A类成熟度仅表示可以开始这些准备，不是期刊或会议录用承诺。
