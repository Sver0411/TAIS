# TAIS MA-1：模块消融与多指标综合评价

日期：2026-11-02（Asia/Shanghai）。本轮在实际TAIS仓库执行，原聊天目录AdaptiveSense未修改。
结论对应**合成软件回放**，不是硬件、自然故障或真实无线测量。

## 1. 完成内容与已有研究复用

完整新增T/S/U八组，保留八个现有控制点，共20种子×54场景×16方法＝17,280次评分运行。
每方法2,720个通道级事件，发送端与接收端合计87,040行逐事件记录。反事实是离线附加执行，
不增加独立样本数。全套测试906 passed、两个既有xfail；新增14项。21,560份原始输入、
逐样本记录、反事实和逐帧档案的SHA256均实际校验通过。

直接复用原C11桥接、Scheduler、AdaptiveSense评分/梯级、Upload U、G2生成器、Binaryv1和独立接收端。
未修改src、vendor及已有实验配置/结果。G1、G2和论文修订验证通过。JO的H失败与SU历史结论保留。
JO-H/S/U不是原SensorTrust开关消融；本轮补齐的正是这项区别。

## 2. 协议与可解释性

见[冻结协议](MODULE_ABLATION_PROTOCOL.md)。A0..A7按任务中的八组合顺序；T＝实际C11门控，
S＝原生每通道AdaptiveSense采样，U＝现有选择性上传。A7精确等于GateOnly+U；JO-SU20/40是额外基线。
T关闭时用明确的中性健康占位，不声称传感器已被诊断正常；所有八组保留相同健康字段布局。
S关闭固定20秒，U关闭每次采样发送。A0/A1/A3/A5严格共享时间网格；每对U开关也共享实际采样时刻。
其余比较报告真实资源，不以补充免费观测实现“等预算”。

46个G2条件全部保留；另有8个预声明补充：1/6次事件、缓慢脉冲、强噪声无事件/有事件、
双通道range/stuck/drift。两通道同时故障只是合成干预，不是实际部署验证。结果同时给出G2与补充分组。
54场景混合权重预先固定，不代表现场发生率。新种子900–919；审计113份当前可访问配置/manifest无冲突，
不声称完成不可访问机器或未记录历史的审计。测试前保存47份有效源码/配置/协议快照。

主匹配按通道一对一、5秒容差、截止min(事件结束+5秒,起始+120秒)。历史原生TP/FP/FI保留在原始表。
迟于截止的报告产生FP并留下FN；这不等于永不检出。漏检在单独的受限延迟损失中计120秒，
不是伪造的实际检测时间。无事件Recall/延迟为N/A。发送报告与独立解码后的接收事件边沿分别评分。

## 4. 模块贡献与统计支持

以整个种子为配对簇，5,000次bootstrap；推断量为种子微平均指标的平均差，与上表合并F1不是同一估计量。
20,000次双侧sign-flip在对称/可交换零假设下计算p，对13对比×6指标＝78项统一Holm校正。
95%区间本身未做多重校正，不能仅因不跨0就宣称显著；完整78项见[paired_effects.csv](../results/module-ablation/test/analysis/paired_effects.csv)。

**SensorTrust：固定采样下作用明确，不能泛化为所有故障都有效。** A1−A0的种子平均F1差+2.32pp
（CI[1.57,3.09]，校正p=0.0039）；FI从380降至182，少198次。Recall差−0.11pp不显著。
分组显示固定采样range的FI148→1，multi_range40→1；drift54→54、stuck5→5、stable_offset65→65。
收益主要来自越界和部分尖峰；采样数窗口限制了短故障的STUCK/DRIFT证据积累。分组区间是描述性。
开启自适应时A7−A6的F1差CI跨0、校正p=1；FI374→112，但Recall30.37%→28.24%，受限延迟增加2.22秒，
后两项有校正后支持。不能称SensorTrust带来稳定全面准确率收益，也不能忽略同通道故障FN变化。

**原生自适应采样：本轮总体退化。** A2−A0 F1−19.68pp有统计支持，并且字节反增11.37%；
A7−A5 F1−22.13pp、受限延迟+17.43秒亦有校正支持。A7事件期间采样6.24次/分钟，固定20秒为2.98；
但事件至少一次有限采样覆盖由96.03%降至83.20%。较高的事件内采样率并未补回进入事件之前的稀疏机会。
强噪声无事件组A7采样6,663次、FP68，固定组1,800次、FP57。原始seed900时间线显示A7的344个周期中，
335个周期请求5秒，噪声确实消耗了高频预算。缓慢脉冲所有所选代表方法120秒内Recall均为0；
原生无截止窗口仍有少量迟检，例如A0为3次、A7为1次，不能写成“从未检出”。

**选择性传输：最清楚的是通信收益及鲜度代价。** A3−A0和A7−A4的采样、检测计数和延迟完全一致，
不是通过“不显著”推断相等，而是逐样本不变量与实际计数校验。A7相对A4少57.79%字节；
A5相对Fixed20少67.08%。四对U开关均未丢失已采样的重要边沿；这只适用于理想本地传输和本轮输入。

**交互：** U不改变检测路径，检测质量的S×U效应为0。字节S×U的95%CI虽不跨0，Holm p=0.162，
不足以宣称稳定协同；T×S的F1交互p=0.054也未通过。T×S在受限延迟与FI上分别p=0.0153/0.0441，
提示可靠性门控与采样机会存在依赖；其中FI交互接近阈值，有限次蒙特卡洛的误差和20种子规模要求后续独立确认。字节三因素交互有支持，但仅描述这套编码、门控和采样组合的资源效应，
不代表检出质量出现协同提升。

## 7. 限制与下一步

不把新54场景、旧G1或700–719的旧G2总数合并。新测试截止窗口也不同于旧原生计分。
种子重复只量化本生成机制的不确定性；人为事件支持标签可早于明显物理偏离，尤其缓慢事件。
Fault overwrite可能消除真实信息；时间命中不证明物理原因。FI反事实可能受采样路径移动影响。
不测自然故障准确率、RF、丢包下真实鲁棒性、电能、CPU开销或田间价值；中性健康占位只限研究适配器。

下一轮先按时间线定位“漏掉首次观测”和“有覆盖但被门控/EMA压制”的比例，独立变化事件幅度、持续时间与故障时长，
明确农业任务允许的延迟/数据年龄。若研究以秒而非样本为单位的可靠性窗口或对缓变的独立检测器，须另立协议与新未用种子；
不能继续在900–919上调参。将A5作为值得独立复核的简单控制点保留，尚不宣布默认替代；继续如实保留JO-H与空间试点等历史NO-GO。

可向峰野教授汇报的重点：已经能够通过完整消融解释各模块的作用；本轮可靠性评价主要抑制特定故障误报，
独立上传以鲜度换取通信节省，而原生自适应采样在事件覆盖和噪声预算上暴露了明确不足。
研究价值是找到可复现的适用边界，而不是给完整组合挑选漂亮指标。
