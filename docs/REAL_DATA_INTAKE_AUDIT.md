## 3. Hull实际结构与质量

### 3.1 实际字段及空间信息

Full Data的实际CSV表头为：

```text
Date,Time,Temperature Front,Humidity Front,Temperature Middle,Humidity Middle,
Temperature Back,Humidity Back,Fan/Wet Wall State
```

| 测点 | 原生发布的观测列 | 单位/位置 | 记录数与覆盖 |
| --- | --- | --- | --- |
|Front|Temperature Front / Humidity Front|℃ / %RH；温室前部标签|45,832行；与其他两处共用Date/Time|
|Middle|Temperature Middle / Humidity Middle|℃ / %RH；温室中部标签|45,832行；共用Date/Time|
|Back|Temperature Back / Humidity Back|℃ / %RH；温室后部标签|45,832行；共用Date/Time|

三处同物理量空间测点确实存在。官方描述是29 m温室隧道、风机与湿帘位于两端；原CSV没有各传感器序列号、XY/GPS坐标或每个设备独立采集时间。位置标签支持相对空间区别，不能从中捏造精确距离或严格同步的瞬时读数。

Full Data也不是原始高频ADC样本。官方方法说明：传感器按分钟采集后作5分钟平均，中部还使用10 s采集、分钟中位值进行控制，再记录5分钟平均。故它是**原生发布的聚合测量**，不是秒级完整信号。CSV未交代聚合时间戳代表窗口起点还是终点、发布时间/传输延迟；共用一行不证明完全相同的测量窗口。

`Fan/Wet Wall State`确实存在，取值F为32,538行、T为13,294行，表示控制状态。它不是独立环境/故障真值，也没有确认每次变更对应的全部原因。

### 3.2 日历编码阻断项

原始第一行时间是 **`1931/12/22 00:06:35`**，最后一行是 **`2014/06/23 00:44:48`**。共有166个不同原始Date标签、166个连续Date块。开始的日期标签依次为：

```text
1931/12/22, 2001/01/23, 2002/01/23, 2003/01/23, ...
```

按字面`%Y/%m/%d %H:%M:%S`，全部可解析，但最小/最大时间变成 **1930-01-23 00:00:50 / 2029-05-23 23:56:28**，且源文件中有5次时间倒退。这显然不能未经说明地当作官方描述的2022–2023年温室采集时间轴。166个标签也不能直接认证为元数据所述162天的连续覆盖。

可能涉及日期格式误读/世纪展开，但**本阶段没有选择解码假设，没有替换日期、补全日历或生成“修复数据”**。需要原导出格式或作者/正式元数据的独立说明，才能判断跨日顺序、覆盖时段、缺失日期以及将来时间块划分。不能只因某种解码看起来合理就据此冻结最终集；不能静默改用V2。本次“能解析”不等于“日历可信”。CSV和已核实元数据没有明确时区；没有自动附加UTC或南非本地时区。

- 45,832数据行、9列。所有字段空单元格为0，六个测量列的非有限/不可解析数值为0；完整重复行0，字面Date+Time重复0。**这些只是已记录单元格的完整性，不是应采样记录的缺失率为0。**

## 4. Intel实际结构与质量

### 4.1 原始格式、身份和测量

原日志无表头，每行固定8个**单个ASCII空格分隔的位置**：

```text
date time epoch moteid temperature humidity light voltage
```

连续空格代表空字段，必须保留位置。例如：

```text
2004-03-02 02:55:32.980639 8875 8 17.7932 42.5178  2.65143
```

这里空的是light，最后一个数仍是voltage。首次只读试解析用任意空白分词暴露了列错位风险，其诊断输出保留为未采用草稿；最终采用保留空字段的单空格解析，并与独立pandas分块读取交叉核对。**原文件从未变化，草稿错误不被计入最终字段结果。** `sep=r"\s+"`会错误地吞掉缺失位置。

变量为℃、温度修正后的%RH、Lux、V，依据官方字段说明；湿度已是温度修正的工程值，不假称完全独立的未校正湿度原始ADC。原日志没有控制状态、执行器命令、设备校准、故障真值、时区或到达时间列。时间精度可到微秒，精度不等于真实采样频率或同步精度。

官方部署/坐标有54个点，`mote_locs.txt`每行ID、x、y，单位米，原点按官方描述在实验室右上方。54个坐标ID均在日志出现。但日志实际有**61个不同非空数值ID**，包括无坐标的55、56、57、58、6485、33117、65407；另有526行moteid为空。不能自动将额外ID映射到邻近位置，不能把空编号行归到前一节点，也没有静默删除它们。ID1–54共有2,303,290条记录，其他数值ID合计9,866条。
