# 离线空间参照探索协议：OSP-1

这是基于真实温室背景和受控干预的离线探索性实验，不是实际在线 LoRaWAN 系统或自然故障诊断的确认性验证。用户此次授权在明确假设下推进离线研究；[C0](REAL_DATA_INTAKE_AUDIT.md)、[C1](REAL_DATA_EXPERIMENT_PREREGISTRATION.md)、[C1.1](C1_1_DATASET_SELECTION.md)的正式在线 NO-GO 原样保留，不要求或联系作者。本协议在任何本实验效果计算前提交，随后开发只修实现错误，不按测试结果增添机制。

所有参考共同相对目标平移 −10/0/+10分钟，参考最大年龄5/15/30分钟，九组合全部报告；它们是假设敏感性，不是测得的延迟。负偏移可允许原代理标签稍晚的记录，但仅因该假设把其可用时刻移早，不能再称真实世界无泄漏。年龄仅是代理可用年龄，不是真正样本年龄。跨分区不借值。

空间拓扑严格用论文Figure7/Table2：上排16/19/…/40，中排17/20/…/41，下排18/21/…/42；没有米制坐标。固定取曼哈顿拓扑最近四个其他节点，平距按AF编号排序，至少两条可用才形成参考。缺参考采用不抑制环境报告的路径，记录覆盖与成本，不能把不可用案例丢掉提高召回。

## 最小方法（独立于旧TAIS算法）

不修改或冒充AdaptiveSense/SensorTrust。此处是独立、可解释的信息实验，不是新闭环TAIS或其原样复现。

1. **HistoryShort**：当前目标值减去过去60分钟有效且不同原行的目标观测中位数，至少3条历史；绝对差达到阈值产生原始事件episode，降至半阈值释放。每episode最多一个起点；缺数据期间保留episode状态，不用缓存重复值制造新证据。
2. **HistoryExtended**：相同事件episode，加过去90分钟目标历史的线性趋势诊断。至少6点、跨度至少50分钟，R²≥0.8且拟合首尾差≥2倍事件阈值，标记“缓慢持续变化证据”。有该证据则抑制新的事件起点；若当前新目标值与上次新值的突变≥阈值，允许起点。此规则会误拒真实局地缓变，必须报告。
3. **Spatial**：同一诊断作用于目标减空间参考中位数的残差；各节点用校准前缀中位数消除静态基准差。所有回归仅使用当刻及过去已可用数据；不以一次空间不一致判故障。仍保留目标突变通道；参考不足时不抑制，不称保证召回。
4. **NullSpatial**：与Spatial相同公式、真实参考请求时刻/可用掩码/成本，但返回与当前目标不相关的校准前缀日片段。固定哈希种子按集/参考节点选择前缀日期，保留日内顺序；前缀缺值用该校准节点中位数并标明。它是合成负对照消息，不伪装真实当刻测量。共同环境干预不注入历史负对照；参考自身仪器故障/缺失同时作用于空间和负对照请求。

HistoryExtended使用更多已取得的目标历史，存储/运算增加，但不凭空收费成额外传感器测量。Spatial与NullSpatial参考请求/响应预算严格相同；不能称它们与无网络历史方法同总成本。突变也可能是故障，稳定偏移与真实阶跃可能不可分，不预设方法有效。

## 独立干预与真值

干预应用在原记录代理时间的背景副本，再由as-of回放取值；不是插值生成隐藏完整信号。日志在检测前独立生成，检测函数只收数值、可用标识和行键，不能访问场景名/标签/未来值。

- 漂移：08:00–12:00线性增加6℃/24%RH，之后保持偏移到20:00；不把恢复骤降混入主漂移结果。
- 稳定偏移：08:00起+6℃/24%RH至20:00。
- 局地快速事件：10:30–11:30目标+3℃/12%RH；共同事件对所有真实空间节点加同一变化。矩形边缘是已知受控干预，不宣称自然事件形状。
- 局地缓慢事件：与漂移完全相同的数值轨迹，但事件标签不同，作为可辨识性边界，不能计为故障识别成功。
- 参考缺失：10:00–14:00四参考均不可用；参考故障：几何顺序第一参考具有上述漂移。无信息对照保持相同可用掩码。

在首轮开发效果之前明确数值支持规则：所有受控副本在加干预后限制于上述分析范围，防止把超过100%RH的数值当真实局地环境事件；漂移/偏移也用相同饱和规则，因此局地缓变与漂移输入仍完全一致。原始值不改；日志记录目标饱和轮询数，幅度是名义请求值，不保证每个样本实现全幅。总体请求召回保留所有干预请求，并另报固定采样窗口内确有非零干预差值的机会分母，零变化/无观测不能伪装成检出成功。

13场景：untouched、drift、offset、local_fast、local_slow、common_fast、drift_local_fast、drift_common_fast、reference_missing、reference_missing_local、reference_fault、reference_fault_local、drift_reference_missing。后两类无事件的参考场景也是必要的配对控制，不删除不利场景。所有方法/对齐点共用潜在背景与干预计划。

## 指标与成本

原始背景可能含未知自然异常，故严格自然误报率/自然召回均N/A。主要报告：

- 有无漂移的环境报告数净差，及按起点±10min一对一匹配后的新增/消失报告数量，称“受控漂移干预额外报告”，不是逐条证明的自然误报；有事件对比保持同一环境干预不变，另报事件窗口外差值。
- 注入事件开始后90min内目标通道一对一匹配的窗口召回；同时报告相对无该事件配对控制**新增报告**的增量响应召回，避免背景报告碰巧落窗。局地快/慢、共同、重合、参考坏/缺分开报告。无事件为N/A。没有目标观测机会的注入仍留在总体分母，另列可观测机会与有机会召回。
- 匹配延迟、未检测数量、参考槽有效率/至少两参考率、目标覆盖、各假设结果。不只报检出样本的短延迟。
- 固定轮询尝试、有效读数、不同原行使用量、重复缓存读取、参考请求数、应用请求/估算字节。它们是离线使用量，不能叫原部署实际采样/发送次数。

固定假设的应用帧：请求 `<BqB` 10字节，响应 `<BqqdB` 26字节（含不可用状态），环境报告 `<BqBd` 18字节。每参考槽每tick各一次请求/响应，即使缺值也返回状态；目标本地读取无网络请求。所有方法报告相同18字节格式。总应用请求=参考请求+环境报告；参考取数不可免费。不是实际LoRaWAN包头、实际传输成功率或无线电电能。

统计以**日期集**为cluster，完整保留同日全部节点/变量/场景配对；节点、窗口和阈值点不当独立温室。固定种子、10000次日期cluster bootstrap给配对差值双侧95%百分位区间；报告各日原始差值、总分母和最少日期数，开发仅6日、保留仅9日，区间有限，不做确认性显著优效/非劣声明。阈值、对齐及全部失败场景都展示，不择优。

## 开发门槛与冻结

先跑单元/因果/无标签/读数账本/成本/重现测试，再开发集。若少于4个日期集、总体目标覆盖<50%或主对齐至少两参考覆盖<50%，停止效果比较，保留实际检查与失败。若方法在开发全部结果中完全一致且无信息增量/代价差异可解释，也不开放保留集；不得不断加机制求正结果。只要出现可复核的收益、损害或局地快慢边界差异，均可作为“有意义的探索发现”进入冻结评估，不能以收益为唯一放行条件。

门槛通过后提交开发输出、固定代码/配置/分析SHA及验证命令；验证只检查冻结规则，若有失败保留真实失败并停止保留评估。保留集评估后不再调参；负结果同样交付。图例集预定为AF29、各分区首个日期、温度、主倍率/主对齐，不能按图好看选择；没有有效读数也画出缺失。完整逐节点指标和独立注入日志保留，原始/大轨迹在仓库外，提交小型CSV/压缩表/图与校验manifest。
