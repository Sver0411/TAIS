## Three policies and the conservative reference rule

GateOnly and original TAIS instantiate the **unchanged Scheduler/C11 SensorTrust** on A alone, multiplier1.0, identical configured temperature units/noise floors and thresholds. B is not mislabeled humidity or fed into those policies. This is the same algorithm in a new one-main-channel setup, not a byte-identical reproduction of the old two-quantity benchmark. Historical regression tests remain.

ReferenceGate uses exactly GateOnly main-channel candidates/intervals. Read A first. At t0 read B once if budget permits; these first actual readings are causal baselines, not clean/healthy-history oracles. On each GateOnly environmental onset, request current B and at the first subsequent scheduled **A** reading at least10s later request B again. Frozen main intervals remain[5,60]s; no extra A polls or B future interpolation. At most one reference job is pending; another candidate remains unresolved(`busy`). A missing baseline/read/budget yields explicit unresolved status, no silent replacement/retry. An incomplete job ends unresolved.

Support requires both A and B displacement from their own first actual baselines to have the same sign and magnitude>**8×0.15=1.2C** at both observations.10s and1.2C directly reuse frozen event duration/threshold/floor. No learned correlation/lag/ratio/α lookup. Static B bias cancels in differences. Persistence/cochange is **environment evidence**, not proof A has no simultaneous drift. If B is flat/inconsistent/unavailable, preserve the original candidate and call cause unresolved; never declare drift from absence of B response. No new fault classifier or confirmation-state tuning.

Reference readings, timestamps and candidate evidence IDs/status/reason are buffered into actual JSON frames; reference decisions can request an additional frame. First admitted evidence for a prior candidate also transmits that candidate, even if its active interval ended. All retained candidate and support reports are separately scored. No untransmitted evidence is credited as receiver-known information. C11 fault flags are recorded independently; their existence is not a calibrated cause probability.
